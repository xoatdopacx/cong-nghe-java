🏗️ Kiến trúc Đa tầng (Multi-tier Architecture)

Hệ thống được thiết kế chuẩn theo mô hình 4 tầng tách biệt:

  1. Presentation Layer (View & Controller): Spring MVC tiếp nhận request, validate dữ liệu đầu vào với Bean Validation, trả về Thymeleaf views kết hợp Thymeleaf Security extras.
  2. Service Layer (Business Logic): Đảm nhận toàn bộ nghiệp vụ kiểm tra tính toàn vẹn (trùng mã sinh viên, trùng mã khóa học, kiểm tra sinh viên đã đăng ký môn học chưa).
  3. Data Access Layer (Repository): Sử dụng Spring Data JPA kế thừa JpaRepository, tự động sinh các truy vấn JPQL và SQL thao tác cơ sở dữ liệu.
  4. Entity Layer: Các thực thể JPA Student, Course, Enrollment và AppUser ánh xạ bảng CSDL với quan hệ @ManyToOne.
  5. Security Layer: Spring Security 6 với DaoAuthenticationProvider, mã hóa mật khẩu bằng BCrypt, bảo mật phân quyền Role-Based Access Control (RBAC).
